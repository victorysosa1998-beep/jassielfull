Excel / CSV Column Format
Columns can be in any order — jaasiel Assistant detects them by name. You can also just have a single "Name" column.
First Name  |  Last Name  |  Date of Birth
Gender  |  Parent Phone  |  Parent Email
For images: just a plain list of names is enough — one name per line.
